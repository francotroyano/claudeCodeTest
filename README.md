# Web personal – Francisco José González Troyano

Web personal profesional en una sola página (`index.html`), con estilo Bento Grid y modo oscuro. Es HTML y CSS estático, sin dependencias ni proceso de build.

## Publicar con GitHub Pages

1. En el repositorio, ve a **Settings → Pages**.
2. En **Source**, elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
3. Guarda los cambios. La web quedará en `https://francotroyano.github.io/claudeCodeTest/`.

## Personalizar

- **Color de acento:** cambia `--accent` en la etiqueta `<style>` de `index.html`.
- **Textos:** se editan directamente en `index.html`.
